This file plans the map system that today is a single hardcoded ring in
=src/map.rs=: a 32x24 grid (=GRID_W=, =GRID_H=), =TILE = 32.0=, four corner
waypoints in =RING=, and a buildability test that is nothing but "further than
=0.95 * TILE= from the path". Every task here moves a constant out of the
source and into an asset (=assets/maps/*.ron=), generalises the path shape, and
adds the Life Zone and per-player lanes that [[file:02-simulation.org][02-simulation.org]] and
[[file:04-waves.org][04-waves.org]] depend on. The map module stays shared by client and server and
carries no authority.

* Path geometry

** TODO [#A] Support the path shapes the real maps use   :@map:
   :PROPERTIES:
   :ID:         map-002
   :EFFORT:     1w
   :BLOCKED-BY: map-001
   :END:
   There is exactly one closed ring through four corners and =Path::sample=
   wraps every distance with =rem_euclid(self.total)=, so no other shape is
   expressible. Generalise =Path= to the classic circle (Lineage A), a
   serpentine, a multi-lane layout and a figure-8, each providing =sample(dist)=
   and =distance_to(p)=.

   - Files: =src/map/path.rs=, =src/map.rs=, =assets/maps/*.ron=
   - Acceptance:
     - [ ] At least four shapes are expressible as waypoint lists and at least two ship (the classic ring and one other).
     - [ ] =sample(dist)= is continuous and, for a closed shape, wraps exactly as today; for an open shape it reports arrival at the Life Zone.
     - [ ] =distance_to(p)= is correct for a leg that crosses the path's own interior (a figure-8 crosses itself).
     - [ ] Building is still forbidden within =0.95 * TILE= of any shape.

* Open questions

  - *Spawn lane count.* Research could not confirm it. Default: one spawn point
    per player (=map-004=), matching =creeps_per_wave()='s player multiplier.
  - *Do Lineage A ring creeps loop forever or stop at the ring end?* Default:
    loop forever on a closed ring, so =Overrun= can accumulate.
  - *Exact build-region ownership layout.* Unconfirmed. Default: equal
    rectangular plots around the ring, one per player, =(tune)=.
  - *Real serpentine, multi-lane and figure-8 geometry.* Not documented in
    measured form. Default: author-defined waypoint lists, marked =(tune)=.
  - *Default spawn direction.* Unconfirmed. Default: clockwise from each
    player's spawn point.
  - *Does the Life Zone ever move or multiply per lane?* Unconfirmed. Default:
    one zone per lane, fixed for the match.
